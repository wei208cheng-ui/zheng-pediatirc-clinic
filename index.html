114年度醫療群績效獎金分配成果
與年度指標改善報告

醫療群聯合會議

嚴謹面對指標，溫柔陪伴病人；最後衝刺，一起把分數拿回來。

一、報告目的

本次不重複列印前期每月案例與已完成分配紀錄。

本次會議聚焦：

  1. 114年度各項績效指標執行成果
  2. 各診所目前得分情形
  3. 表現較佳診所經驗分享
  4. 尚未取得分數或得分偏低項目
  5. 剩餘兩個多月的最後衝刺策略
  6. 透過醫療群彼此分享，提升整體群體績效
核心提醒：這不是單一診所的競爭，而是整個醫療群一起把病人照顧好、把指標做扎實。

二、114年度整體績效執行現況

本年度指標不是單純比較「病人數多寡」。

真正鼓勵的是：

  • 主動執行
  • 積極照護
  • 持續追蹤

目前結果顯示：

  • 即使診所病人數不多，只要願意積極執行，也有機會取得相同指標分數。
  • 最後兩個多月仍然具有相當大的改善空間。
鼓勵：不是等病人自己來，而是我們主動發現、主動安排、主動追蹤。

三、成人健康檢查

目前成果

共有 4家診所取得6分。

這項指標值得特別強調：不是只有病人數多的診所才能取得高分。

表現需要積極診所

曜廷診所宏安診所崇堯診所

改善方向

把成人健康檢查融入日常門診流程，尤其是慢性病患者、中高齡患者、定期回診患者、原本就需要抽血檢查患者。

不要等待病人主動要求，而是在日常診療中主動發現適合接受健檢的病人。

目前需要加強診所

看診 → 確認篩檢資格 → 查詢過去檢查紀錄 → 適合者主動提醒 → 協助轉介至媽媽咪亞診所篩檢。

重點不是增加病人負擔，而是把預防保健融入原本的醫療流程。

六、糞便篩檢執行率

目前成果

目前「順便篩檢」成果並不理想。目前僅有 康貝兒診所 取得分數。

實際執行困難

病人答應 → 離開診所 → 最後沒有完成檢查。

尤其在市區型診所，病人生活忙碌，後續追蹤更加困難。

建議策略

  1. 能否在病人當次就診時完成
  2. 能否與原本必要抽血一起進行
  3. 能否利用慢性病回診時順便完成
  4. 能否在大家醫平台或健保資料中確認既有檢查狀況
  5. 減少「開單後等待病人自己完成」的流程
提醒：能當次完成，就不要留給下一次；能順便完成，就不要多開一趟。

十五、血脂肪控制

自8月份開始，血脂肪控制也是重要的改善方向。

核心策略

熟悉的慢性病患者，就是最容易進行改善的對象。

因為這些病人：

  • 已經建立醫病關係
  • 已有固定回診
  • 有既往檢驗資料
  • 容易進行後續追蹤

十六、糖尿病患者胰島素注射

目前成果

目前共取得 3分。其中 鄭煒達診所：5分。

本次會議

由鄭煒達診所分享實際執行經驗。

糖尿病患者 → 評估 → 適當使用胰島素 → 教導注射 → 持續追蹤 → 血糖控制

十七、最後兩個多月的衝刺策略

把已經可以做到的事情，在最後階段確實做到。

第一層：先守住已經有的分數

避免原本已經取得的項目在最後階段下降。

第二層：優先攻擊高分項目

6分項目、10分固定就診率、CKD、LDL控制、會員急診率降低、可避免住院預防。

第三層：利用既有病人完成指標

慢性病患者、固定回診患者、中高齡患者、BMI偏高患者、已有抽血需求患者、糖尿病患者、高血壓患者、氣喘患者、產前檢查患者。

十九、報告結論

真正影響績效的核心，是：

主動發現 → 主動篩檢 → 主動追蹤 → 積極治療 → 持續管理。

最後階段的目標不是單一診所競爭，而是：

讓每一家診所都把自己最有機會取得的分數盡量拿到，進一步提升整個醫療群114年度的整體績效。

二十、會議最後五大重點

  1. 前期獎金已完成分配，本次重點是年度成果與最後衝刺。
  2. 高分診所經驗要分享，讓成功模式可以被其他診所複製。
  3. 優先搶攻6分、10分等高價值指標，避免可取得的分數白白流失。
  4. 善用既有慢性病及固定回診患者，把篩檢、抽血、糖尿病、血脂、CKD等工作融入日常門診。
  5. 最後兩個多月仍然可以改變年度成果，現在開始衝刺仍然值得。

嚴格把關，溫暖鼓勵

醫療衛教要嚴謹，照顧病人要溫柔。

指標不是壓力，而是提醒我們：還有很多病人可以被主動照顧到。

最後兩個多月，一家診所多問一句，一位病人多完成一項篩檢，整個醫療群就會往前一步。

一起衝刺，一起把114年度做得更好。
